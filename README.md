## 🚀 Featured Project

### 🧠 Psychotest Web Application

A web-based psychological testing application developed using:

**Next.js • React • TypeScript • Node.js • Tailwind CSS • MySQL**

✨ **Key features:**

* 📝 Psychological test management and assessment
* 👤 User and role management
* 💳 Test purchase and payment integration
* 📊 Test result processing and reporting
* ✍️ Psychologist validation and digital signature
* 🔐 Object-Level Authorization (OLA)
* 📄 PDF report generation and verification

This project also became the basis of my final thesis, focusing on **web application security, Object-Level Authorization, and ED25519 digital signatures**.
